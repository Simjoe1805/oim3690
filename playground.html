FAQ

These answers collapse and expand with native HTML details elements, so the interaction works without any extra libraries.

What colors shape this page?
The palette is built around black, white, and Babson Green, using the official Babson web green value of #006644.
Is the video centered on all screen sizes?
Yes. The Shorts iframe sits inside a flex container that keeps it centered, and the width scales down cleanly on phones.
Why is the audio embedded from SoundCloud?
The official SoundCloud player is embeddable and more dependable here than the music-label YouTube widget, while still keeping the song sourced from the artist account.
How was the favicon added?
The page starts with an inline SVG favicon and then upgrades it at runtime to a PNG generated from the canvas badge.
