## code I am proud of 
function calculateSMA(values, period) {
  const result = Array(values.length).fill(null);
  let rollingSum = 0;

  for (let index = 0; index < values.length; index += 1) {
    rollingSum += values[index];
    if (index >= period) {
      rollingSum -= values[index - period];
    }
    if (index >= period - 1) {
      result[index] = rollingSum / period;
    }
  }

  return result;
}

- this code calculates a Simple Moving Average for an array of numbers, usually stock closing prices, it also values is the price list. the period is how many values to average, like 5 days or 20 days.
